# Orcus APK Emulator 설치 안내

선생님과 학생이 Windows PC에 Orcus를 설치할 때 보는 안내입니다. 설치 파일은 저장소의 `release/OrcusAPK-Setup-<버전>.exe` 하나입니다(약 28 MB). 개발자는 `py tools/dev.py build --release`로 다시 만들 수 있습니다.

## 준비

- Windows 10 2004 이상 또는 Windows 11, 64비트
- 설치할 드라이브에 24 GB 이상의 빈 공간(설치가 끝나면 약 14 GB를 씀)
- 인터넷 연결(처음 한 번 Google에서 약 2.4 GB를 받음)
- 관리자 권한은 필요 없습니다. Windows 하이퍼바이저 플랫폼이 꺼져 있으면 켤 때 한 번만 권한(UAC) 창이 뜹니다. 관리자 암호가 없으면 마법사가 만들어 주는 IT 요청문을 관리자에게 보내세요.

## 설치

1. `OrcusAPK-Setup-<버전>.exe`를 실행합니다.
   - 서명하지 않은 프로그램이라 "Windows의 PC 보호" 창이 뜰 수 있습니다. [추가 정보] → [실행]을 누르세요.
2. **Orcus 폴더**를 고릅니다. 기본값은 `D:\OrcusAPK`이고, 고정 D: 드라이브가 없으면 `C:\OrcusAPK`입니다.
   - 영문·숫자로 된 40자 이하 경로여야 합니다. 한글이 들어간 폴더와 Google Drive 폴더는 쓸 수 없습니다.
   - 프로그램은 그 안의 `app` 폴더에 들어갑니다.
3. ".apk 파일의 '연결 프로그램'에 추가"를 켜 두면, 탐색기에서 .apk를 오른쪽 클릭한 뒤 [연결 프로그램]으로 바로 열 수 있습니다. .apk의 기본 프로그램은 바꾸지 않습니다.
4. 설치가 끝나면 Orcus를 엽니다.

## 처음 열 때: 설치 마법사

휴대폰 파일이 아직 없으면 메인 창보다 설치 마법사가 먼저 뜹니다. [설치 시작]을 누르면 아래 순서로 진행합니다.

1. **PC 점검:** 폴더와 빈 공간을 확인하고, 이 Windows 계정만 Orcus 폴더를 쓸 수 있게 잠급니다.
2. **라이선스 동의:** Google Android SDK 라이선스 전문을 끝까지 읽어야 [동의합니다]가 켜집니다. 한국어 요약은 참고용입니다. **동의는 반드시 본인이 직접** 합니다.
3. **Windows 하이퍼바이저 플랫폼 켜기:** 꺼져 있을 때만 나옵니다. [켜기] → 권한 창에서 [예].
4. **내려받기·압축 풀기:** 10–20분 걸립니다. 닫아도 다음에 열면 이어서 받습니다.
5. **Windows 다시 시작:** 3에서 기능을 켰다면 한 번 다시 시작해야 합니다. 다시 로그인하면 마법사가 저절로 열려 남은 단계를 마칩니다.
6. **완료:** [시작]을 누르면 창이 열리고, 가상 휴대폰을 처음 한 번 준비합니다(약 5분). 그동안 창을 닫지 마세요.

## 화면 언어

[설정] > [언어 (Language)]에서 자동(Windows 언어)·한국어·English를 고릅니다. Orcus를 다시 시작하면 바뀝니다.

## 제거

Windows [설정] > [앱] > [설치된 앱]에서 Orcus APK Emulator를 제거합니다. Orcus가 열려 있으면 먼저 닫으세요.

- 마지막에 "Orcus 폴더에 남은 가상 휴대폰, 내려받은 SDK, 로그와 설정도 지울까요?"를 묻습니다.
  - **[아니요]**(기본): 남겨 둡니다. 다시 설치하면 내려받기와 라이선스 동의 없이 그대로 씁니다.
  - **[예]:** Orcus가 만든 폴더만 지웁니다. 같은 폴더에 둔 다른 파일은 지우지 않습니다.

## 실습실에서 여러 PC에 설치할 때

- 무인 설치: `OrcusAPK-Setup-<버전>.exe /VERYSILENT /HOME=D:\OrcusAPK`
- 무인 제거: `<Orcus 폴더>\app\unins000.exe /VERYSILENT` (데이터까지 지우려면 `/DELETEDATA=1`)
- 라이선스 동의는 PC와 Windows 계정마다 사람이 마법사에서 직접 해야 합니다. 자동으로 동의하는 방법은 없습니다.
- 백신(AhnLab V3 등)이 중앙 관리되는 PC에서 SDK 파일이 사라지거나 잠기면, 마법사의 [IT 요청문 복사]로 검사 예외를 요청하세요.
